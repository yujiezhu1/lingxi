# 灵犀 · 界面设计说明

v0.6.0 重新设计界面时的方向和设计系统，后续改动请沿用。

## 方向

- **主题**：灵犀是一个让多个 AI agent 的工作「接上线」的地方。名字取自「心有灵犀」，早期代号 Weft（纬线），所以视觉上用**线与编织**作为核心隐喻，配色取自**青瓷与水墨**。
- **用户**：同时开着 Claude Code、Codex、pi、豆包、WorkBuddy 的开发者。
- **首页的唯一任务**：一眼看清「今天每个 agent 都在干什么、它们之间传了什么、哪些事需要我处理」。

刻意避开的常见 AI 生成界面风格：奶油底 + 衬线 + 赤陶色、黑底 + 荧光色、报纸式细线排版、首页大数字统计卡片。

## 设计系统

| 角色 | 值 | 用途 |
|---|---|---|
| 瓷底 porcelain | `#EEF2EE` | 页面背景 |
| 素纸 paper | `#FBFCFA` | 面板 |
| 墨 ink | `#16201C` | 正文 |
| 苔灰 moss | `#5D6B64` | 次要文字 |
| 青瓷 celadon | `#2E6B5E` | 主色：选中、链接、主按钮 |
| 铜金 brass | `#B7832F` | **唯一强调色**：织机上的结点、未读、需要关注 |
| 细线 line | `#DCE3DE` | 边框、分隔线 |

agent 颜色（只用于标识 agent，不做装饰）：Claude Code `#D97757`、Codex `#10A37F`、pi `#6E56CF`、豆包 `#E5A000`、WorkBuddy `#1C8AD6`、Cursor `#3B5BDB`。

| 字体角色 | 字体 | 用在哪 |
|---|---|---|
| 标题 | Noto Serif SC（思源宋体） | 页面标题、面板标题、工作线和交接包标题、Markdown 标题。克制使用 |
| 正文 | Noto Sans SC / 微软雅黑 UI | 其他所有文字 |
| 数据 | Cascadia Mono / Consolas | 路径、会话引用、分支、时间轴刻度 |

圆角 10px（面板）/ 8px（控件），阴影极轻，留白充足。

## 标志性元素：今日织机

首页顶部的 SVG 时间轴，每个视觉元素都对应真实数据，不做装饰：

- 每个 agent 一条泳道；每个会话的活跃时段画成一段线（相隔 40 分钟以上的活动拆成两段）；同一 agent 同时开多个会话时最多叠成 3 行。
- **铜金结点** = 这一时刻保存了交接包或知识卡片。
- **虚线箭头** = 会话之间的消息，从发送方泳道指向接收方泳道。
- 现在的时刻用青瓷虚线标出。
- 首次载入时线条依次「织」出来（约 1 秒，尊重系统的「减少动态效果」设置）；悬停显示详情，点击打开会话、工作线或消息。

其他页面保持安静：工作线详情页的交接包按阅读文档排版（标题用宋体，正文宽度约 74 个字符），知识卡片放在右侧，做成「批注」样式（顶部色条表示类型）；会话阅读页把连续的工具调用折叠成一行。

## 素材

- `concepts/01_today_loom.webp`、`concepts/02_topic_detail.webp`：用 image-gen 生成的概念图（实现时只沿用版式和配色，去掉了概念图里编造的内容，比如负责人头像、收藏按钮）。生成参数在 `concepts/jobs.json`。
- 侧边栏底部的水墨山水：image-gen 生成（带透明通道，约 34 KB），以 data URI 内嵌在 `web/src/ink.css` 里；原图在 `assets/ink.webp`。
- 概念图和原始图片只保存在本地、不进 git（公司网络的上传过滤会拦截图片文件），需要时用 `concepts/jobs.json` 重新生成。

## 检查方法

`bash scripts/ui-shot.sh <名称> <路由> [高度]` 用 Edge 无头模式截图正在运行的 `lingxi ui`，页面加 `nolive=1` 以关闭实时推送（否则截图会一直等待）。
